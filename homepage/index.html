RoboAtom

Large-scale Atomic-Action Supervision for Robot Learning

Paper GitHub Dataset Models

Abstract

Fine-grained action annotations can support skill reuse and compositional generalization in robot policies. However, robot datasets typically provide task-level instructions without subtask annotations. Although some include subtask labels, inconsistent formats and conventions hinder cross-source joint training. We propose RoboAtom-Data, which adds unified, time-aligned atomic-action annotations to existing data from multiple sources, covering 1.45 million trajectories, 6.88 million skill-labeled segments, and 16,882.1 hours. Our pipeline combines a unified protocol, large-scale manual annotation, propagation across repeated executions with the same ordered skill sequence, and multi-stage quality control. We evaluate the dataset through automatic atomic-action annotation and robot control. We construct RoboAtom-Bench to standardize evaluation of skill recognition and temporal boundary localization. Trained on the annotated data, RoboAtom-Anno achieves better automatic annotation performance than all evaluated open- and closed-source models on both RoboAtom-Bench and the external WGO-Bench. For robot control, atomic-action supervision paired with hierarchical execution improves task success over task-level baselines on LIBERO-Long, LIBERO-Plus, and RoboTwin

RoboAtom-Bench ↗

RoboAtom-Bench evaluates which actions occur, their order, and their temporal boundaries. Its subsets cover short, medium, and long action sequences, together with synchronized multi-camera videos

RoboAtom-Anno ↗

RoboAtom-Anno learns from atomic-action supervision to annotate robot videos automatically, predicting skill categories, action descriptions, and temporal boundaries. The results below show annotation performance and inference cost

Dual-system execution

Atomic-action supervision connects high-level planning with robot execution. System 2 selects the current action from observations and execution history, while System 1 converts that instruction into robot movements
